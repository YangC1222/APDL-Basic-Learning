今日目标

用 APDL 建立轴对称燃料棒稳态热分析：在 UO₂ 芯块内施加体积发热率，在包壳外表面施加冷却剂对流边界，并提取最高温度。

物理问题

模型采用 SI 单位制（m、kg、s、K、W、Pa）。燃料半径为 4.10 mm，包壳外半径为 4.75 mm，轴向建模长度为 0.10 m。为突出热源与对流命令，本课把燃料和包壳视为理想结合，不考虑真实气隙热阻；实际燃料棒分析必须在后续课程加入间隙导热或热接触。

  • UO₂ 导热率：3.0 W/(m·K)
  • 包壳导热率：16.0 W/(m·K)
  • 燃料体积发热率：2.0×10⁸ W/m³
  • 冷却剂体温：570 K
  • 对流换热系数：2.5×10⁴ W/(m²·K)

关键命令

  • ET,1,PLANE55：定义二维稳态热传导单元。
  • KEYOPT,1,3,1：启用轴对称选项，X 坐标表示半径。
  • MP,KXX：输入各向同性导热率。
  • RECTNG：建立燃料和包壳截面区域。
  • AGLUE,ALL：粘合公共边界，保证理想温度连续。
  • AATT：给选中区域分配材料与单元类型。
  • BFE,ALL,HGEN,,qvol：向燃料单元施加体积热源。
  • SFL,ALL,CONV,h,Tbulk：向包壳外表面线施加对流边界。
  • *GET,...,MAX,TEMP：提取节点最高温度。

完整脚本

见同目录 [example.inp](example.inp)。脚本按参数、几何材料、网格、载荷、求解和结果导出分段。

预期结果

最高温度应位于燃料中心线附近，温度沿半径方向向冷却剂单调下降。芯块内存在体积发热，包壳只传导热量，因此燃料温降通常占主要部分。脚本未经 MAPDL 实际求解，不预报数值结果；运行后应检查 lesson3_results.txt 和温度云图。

验证清单

  1. **单位检查**：毫米参数均乘 1e-3 转换为米，热源使用 W/m³。
  2. **能量平衡**：燃料总发热应接近包壳外表面对流带走的热量；可在后续用反力热流求和核查。
  3. **边界检查**：只在 X=r_clad 的外壁线上施加对流，中心线不施加固定温度。
  4. **网格检查**：将 esize_r 从 0.20 mm 减为 0.10 mm，比较最高温度变化。
  5. **物理趋势**：增大 qvol 应升高最高温度；增大 hconv 应降低包壳与冷却剂之间的温差。

常见错误

  1. 将线功率 W/m 直接填入 HGEN：应先按燃料截面积换算为 W/m³。
  2. 对所有单元施加热源：会错误地让包壳自身发热；必须先按材料号选择燃料单元。
  3. 把外壁温度直接固定为冷却剂温度：这会忽略膜温差，应使用 CONV 对流边界。

练习题

  1. 把 qvol 分别改为 1.5×10⁸、2.0×10⁸ 和 2.5×10⁸ W/m³，导出最高温度并检查线性趋势。
  2. 将对流换热系数降低 30%，模拟冷却能力下降；比较包壳外壁温度和燃料最高温度，并说明哪一项增幅更明显。
本课是命令学习模型。真实反应堆分析需使用经验证的温度相关材料参数、气隙模型、功率分布、冷却剂边界及安全准则。

完整 example.inp

! Lesson 3 - axisymmetric fuel rod with volumetric heat and convection
! SI units: m, kg, s, K, W, Pa
/CLEAR
/FILNAME,lesson3_fuel_heat
/PREP7

! ---- Parameters ----
r_fuel  = 4.10e-3
r_clad  = 4.75e-3
length  = 0.10
k_fuel  = 3.0
k_clad  = 16.0
qvol    = 2.0e8
hconv   = 2.5e4
tbulk   = 570.0
esize_r = 0.20e-3

! ---- Element and materials ----
ET,1,PLANE55
KEYOPT,1,3,1
MP,KXX,1,k_fuel
MP,KXX,2,k_clad

! ---- Axisymmetric r-z geometry (X=r, Y=z) ----
RECTNG,0,r_fuel,0,length
RECTNG,r_fuel,r_clad,0,length
AGLUE,ALL

! Fuel area: centroid radius below r_fuel
ASEL,S,LOC,X,0,r_fuel
AATT,1,,1
! Cladding area: centroid radius above r_fuel
ASEL,S,LOC,X,r_fuel,r_clad
AATT,2,,1
ALLSEL,ALL

! ---- Mesh ----
ESIZE,esize_r
AMESH,ALL

! ---- Fuel volumetric heat generation only ----
ESEL,S,MAT,,1
BFE,ALL,HGEN,,qvol
ALLSEL,ALL

! ---- Coolant convection on outer cladding surface ----
LSEL,S,LOC,X,r_clad
SFL,ALL,CONV,hconv,tbulk
ALLSEL,ALL
FINISH

! ---- Steady thermal solution ----
/SOLU
ANTYPE,STATIC
SOLVE
FINISH

! ---- Results ----
/POST1
SET,LAST
PLNSOL,TEMP
*GET,tmax,NODE,0,MAX,TEMP
*CFOPEN,lesson3_results,txt
*VWRITE,tmax
('Maximum nodal temperature [K] = ',E16.8)
*CFCLOS
FINISH
