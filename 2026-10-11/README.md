# 第29课：错误捕获、模型数据库恢复与批处理重算

## 今日目标

建立可检查失败原因、恢复模型数据库并可靠重算参数点的APDL批处理。区分模型恢复与真正的瞬态分析重启动。

## 物理问题

等效燃料或控制棒采用PLANE55轴对称热模型，半径4 mm、长度40 mm，常导热率3 W/(m·K)。均匀生热率依次为1.2、1.4、1.6×10⁸ W/m³；外壁对流系数20000 W/(m²·K)，冷却剂573 K，两个端面绝热。单位为m、W、K。图为非比例子午面，没有包壳、间隙或接触层。

这些物性和边界仅用于学习，不是从今日TBM或涂层论文提取的工程参数。保持新目录、独立作业名和完整输入记录，禁止在用户已有求解实例执行清除命令。

## 关键命令

| 命令 | 本课作用与边界 |
|---|---|
| `SAVE,baseline,db` | 保存几何、网格和参数；本课在施加热载荷前保存。 |
| `/CLEAR,NOSTART` | 清除内存数据库；文件仍在磁盘，变量也会清除。 |
| `RESUME,baseline,db` | 恢复数据库及其中参数。不能把它解释为恢复全部瞬态历史。 |
| `*IF` | 在求解前拒绝不合法物性与边界，保留可检查的错误标记。 |
| `/EXIT,NOSAVE` | 仅退出本脚本所在独立MAPDL实例，保留有效检查点。 |
| `ANTYPE,STATIC,NEW` | 每个参数点独立稳态求解；不是三个连续时间步。 |
| `*CFOPEN` / `*VWRITE` | 写入结果和状态文件；格式行紧跟写命令且无行尾注释。 |
| `SET,LAST` / `*GET` | 读取本参数点求解结果，再用解析值和热平衡核对。 |

## 完整脚本

下载本页`example.inp`。脚本先建模并保存数据库，清除内存后恢复，再检查导热率和换热系数，最后重算三个参数点。每条可执行命令均有中文行尾说明。

本课演示的是“数据库恢复后重新计算独立稳态参数点”。真正的瞬态或非线性多帧重启，还需要相应的重启文件、载荷步/子步与匹配求解器版本，并按官方`RESCONTROL`和`ANTYPE,,REST`流程执行。不能只读一个`.db`就声称继续了原瞬态状态。

## 预期结果

解析外壁温度为`Tb + qR/(2h)`；中心温度为`Tb + qR/(2h) + qR²/(4k)`。三个工况的解析中心温度分别为745、773.6667、802.3333 K，外壁温度为585、587、589 K。这些是理论参考，数值误差应由实际结果表计算。

`batch_results.csv`有3行7列：参数点编号、生热率、数值中心温度、数值外壁温度、解析中心温度、温升相对误差、热平衡误差。`batch_complete.txt`只表示已走到写表末尾；还须检查日志、行数、有限值和解析误差。退出码为0也可能是主动拒绝输入，不能单独据此判定成功。

## 验证清单

- 检查m/W/K单位一致，生热率必须为W/m³。
- 确认数据库恢复后的半径、材料和网格数量与保存前一致。
- 确认只在外壁施加对流，端面保持自然绝热。
- 用温升而非绝对温度计算误差，并核对整体热量平衡。
- 在独立失败目录令`hcoef=0`，应写出`BAD_H`且不产生完成标记；修正后在新的重试目录运行。字符标记不超过8个字符，以避免APDL字符写入截断。
- 在独立细网格目录将尺寸减半，比较中心温升误差；保留各次输入与输出。

## 本次隔离验证结果

MAPDL实际求解了三个独立稳态热源工况，结果表为3行7列；中心温升相对解析式的最大误差为0.2868%，整体热量平衡相对误差为1.89×10⁻¹⁴。网格尺寸由0.25 mm减为0.125 mm后，中心温升最大误差下降至0.0822%。在另一个独立目录将对流系数设为0，程序写出`BAD_H`并拒绝生成结果与完成标记。求解退出码、日志、标记和数值同时检查才构成验证；这些结果不证明真实材料参数或连续瞬态重启动正确。详细记录见`validation/validation-summary.json`。

## 常见错误

1. 清除数据库后还使用旧内存参数：先恢复保存的数据库，再施加载荷。
2. 把旧目录中的完成标记当作本次成功：每次运行使用新目录，并核对输入摘要、结果更新时间和日志。
3. 将稳态重算写成瞬态重启动：本课明确采用`STATIC,NEW`；连续物理时间重启需要另行验证重启文件和状态。

## 练习题

将导热率改为6 W/(m·K)，预测并核对中心温度；不要把另一输入的旧结果表用于比较。扩展到燃料—包壳间隙模型时，分别保存材料、接触和载荷定义，并设计一次缺失接触参数的拒绝输入检查。只有通过正确工况的基准验证后，才讨论自动跳过已完成参数点。
